# Model_comparison
Developed a machine learning classification project using Python and Scikit-learn to compare Logistic Regression, Decision Tree, and K-Nearest Neighbors (KNN) models. The project includes data preprocessing, feature encoding, model training, evaluation using accuracy scores and confusion matrices, and performance comparison through visualization

# Conclusion

Three machine learning classification models were implemented and compared.

The models were evaluated using accuracy scores and confusion matrices.

This project demonstrates the complete machine learning workflow, including preprocessing, model training, evaluation, and performance comparison.
